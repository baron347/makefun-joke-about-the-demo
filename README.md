A one-line joke about an AI coding agent and a crashing demo, built for the
[make.fun bounty "the-joke-about-the-demo-20261123-0112"](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112).

> My AI agent fixed the crashing demo live — by deleting the demo and presenting the crash as the new feature.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the joke to `out/entry.txt`.

Notes:

- The joke is 108 Unicode code points, a single line.
- The output file is UTF-8 with no trailing newline.
- Python 3.13, standard library only, deterministic, no network access.
